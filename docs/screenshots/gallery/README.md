# Sankey Studio screenshot gallery

A tour of every screen and section of the interface, in reading order, shot with made-up demo data (light theme unless the file name ends in `-dark`).

* ![Library, empty](01-library-empty.png) Library with no graphs yet: the empty state offers a first graph or a bundle import.
* ![Library, populated](02-library-populated.png) Library with collections, tag chips and graph cards, plus the Import and Export entry points.
* ![Library, dark](03-library-populated-dark.png) The same library in the dark theme.
* ![Inside a collection](04-library-collection.png) Inside the Finance collection: breadcrumb, a sub-collection, "New graph here" and "Export this collection".
* ![Search results](05-library-search-results.png) A search looks at every collection and shows the collection path on each result.
* ![Selection mode](06-library-selection.png) Two graphs ticked: the selection bar offers Compare, Move to collection and Export selected.
* ![Move dialog](07-library-move-dialog.png) The Move dialog, a tree of places with "Move here".
* ![New collection dialog](08-library-new-collection-dialog.png) Creating a collection.
* ![Import dialog](09-library-import-dialog.png) Importing a graph bundle: the dialog shows what the file holds before anything is imported.
* ![New graph, step 1](10-new-wizard-details.png) New graph wizard, step 1: name, description and tags.
* ![New graph, step 2](11-new-wizard-source.png) New graph wizard, step 2: choose where the data comes from (here pasted CSV).
* ![Editor after saving](12-editor-saved.png) The editor with live chart preview, the save bar and the "Saved as revision" toast.
* ![Editor, dark](13-editor-dark.png) The editor in the dark theme.
* ![Data source: Paste](14-editor-source-paste.png) Data source, Paste tab, with the "How to read the data" column mapping.
* ![Data source: Text file](15-editor-source-text-file.png) Data source, Text file tab: a file from the sources folder and the write-back status line.
* ![Data source: Upload](16-editor-source-upload.png) Data source, Upload tab: drop zone and the list of stored files.
* ![Data source: Manual](17-editor-source-manual.png) Data source, Manual tab: a table of links typed in by hand.
* ![Data source: MongoDB](18-editor-source-mongodb.png) Data source, MongoDB tab before any connection exists.
* ![Transform](19-editor-transform.png) The Transform section next to Data source: filters, hidden and merged nodes, category rules.
* ![Entries and categories](20-editor-entries.png) The Entries table: one row per flow with an editable category.
* ![Entries search and bulk category](21-editor-entries-search.png) Searching the entries offers a bulk "Categorise all entries matching this filter" rule.
* ![Chart settings: Style](22-editor-chart-style.png) The chart settings popover, Style tab: title, direction, colours, numbers, nodes and donut options.
* ![Chart settings: Export](23-editor-chart-export.png) The chart settings popover, Export tab: size, colours and download buttons.
* ![Order nodes](24-editor-order-nodes-dialog.png) The Order nodes dialog: move nodes up and down inside each column.
* ![Add a flow](25-editor-add-entry-dialog.png) The Add a flow dialog with the hint for a node that will be created.
* ![Write-back consent](26-editor-write-back-dialog.png) "Change your data too?": the consent question before an edit is written into a source file.
* ![Graph details](27-editor-graph-details-dialog.png) The graph details dialog: name, description and tags.
* ![Change data source](28-editor-change-source-dialog.png) The Change data source dialog, one choice per source kind.
* ![Leave without saving](29-editor-leave-dialog.png) The unsaved-changes guard shown when leaving the editor.
* ![Viewer, Sankey](30-viewer-sankey.png) The viewer: header, totals, the Sankey with its legend and the table view of the links.
* ![Viewer, Sankey, dark](31-viewer-sankey-dark.png) The viewer in the dark theme.
* ![Viewer, donut and display options](32-viewer-donut-display-options.png) The Donut tab with the view-only display options open (percentages and values on the slices).
* ![Viewer, donut, dark](33-viewer-donut-dark.png) The Donut tab in the dark theme.
* ![Viewer, export menu](34-viewer-export-menu.png) The export popover of the viewer: image size, file colours and SVG, PNG, HTML, JSON and CSV downloads.
* ![Viewer, links table](35-viewer-links-table.png) The sortable table view of the links under the chart.
* ![Compare](36-compare-light.png) Compare view with one graph shown as a donut next to another as a Sankey, sharing one colour per category.
* ![Compare, empty](37-compare-empty.png) Compare with nothing selected yet.
* ![Settings: appearance and storage](38-settings-appearance-storage.png) Settings, Appearance (theme cards) and Storage (where graphs are kept).
* ![Settings: connections and limits](39-settings-connections-empty.png) Settings, MongoDB connections (empty state) and Limits.
* ![Settings: a connection](40-settings-connection-added.png) A stored MongoDB connection: the connection string is masked and never shown again.
* ![Settings: this server](41-settings-this-server.png) Settings, Limits and the read-only "This server" facts.
* ![Settings, dark](42-settings-appearance-dark.png) Settings in the dark theme.
* ![Page not found](43-error-404.png) The 404 page.
* ![Theme switch, light](44-theme-switch-light.png) The header with the System, Light and Dark theme switch, light theme.
* ![Theme switch, dark](45-theme-switch-dark.png) The same header in the dark theme.
